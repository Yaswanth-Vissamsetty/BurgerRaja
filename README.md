## 🧾 Overview
**BurgerRaja** is a clean, modern, and fully responsive single-page website built using **HTML, CSS, and Bootstrap**.  
It’s designed for a fast-food restaurant to showcase their menu, contact details, booking form, and more — with an attractive design that looks great on all devices.

🔗 **Live Demo:** [https://yaswanth-burger-raja.netlify.app/](https://yaswanth-burger-raja.netlify.app/)

---

## ✨ Features
- Hero section with a bold call-to-action (“Order Now”)  
- Menu with multiple categories — *All, Burger, Pizza, Pasta, Fries*  
- “Book A Table” form with input fields for easy booking  
- Contact and location information with city, email, and phone number  
- Opening hours and “All Rights Reserved” footer  
- Mobile-friendly, responsive layout using Bootstrap grid system  
- Simple to edit and deploy — no backend setup needed

## 💻 Getting Started — Run Locally

1. Clone this repository:

   ```bash
   git clone <your-repo-url>
   cd <your-repo-folder>
   ```
2. Open `index.html` directly in your browser, **or** run a local server:

   ```bash
   python -m http.server 8000
   # Then open http://localhost:8000
   ```

✅ No build tools or dependencies required — it’s a pure static site.
